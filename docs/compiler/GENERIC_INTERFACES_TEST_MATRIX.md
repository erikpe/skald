# Generic-Interface Conformance Matrix

Status: authoritative traceability map for the implemented generic-interface
language and compiler contracts. The contracts define behavior; this document
identifies the executable evidence that protects it.

Test names below are stable semantic descriptions rather than milestone
identifiers. Owner-local tests prove the narrow phase contract, while the
[generic-interface golden suite](../../tests/golden/generic_interfaces/README.md)
proves complete source-to-native composition.

## Modules, phases, target, and diagnostics

| Contract rule | Primary executable evidence |
|---|---|
| Templates participate in ordinary private-by-default module lookup, imports, aliases, qualification, collisions, cycles, and definition-site name resolution; arguments resolve at the application site. | `interface_template_module_declarations_and_imports_preserve_their_kind`, `resolves_qualified_interface_signature_names_across_cyclic_modules`, and `closed_interface_arguments_resolve_in_the_application_module` in [resolver interface tests](../../crates/skald-compiler/src/resolve/tests/interfaces.rs), plus the private-template golden. |
| HIR and MIR contain only ordinary closed interface and requirement identities—never parameters, templates, structural applications, dictionaries, or runtime type arguments. | `closed_generic_interfaces_lower_as_ordinary_exact_mir` and `rejects_corrupt_closed_generic_interface_identities` in [MIR interface tests](../../crates/skald-compiler/src/mir/tests/interface_dispatch.rs). |
| Preliminary and final MIR independently verify declarations, conformances, signatures, receiver access, call targets, ownership, effects, and complete-object metadata. | Interface mutation corpus in [MIR interface tests](../../crates/skald-compiler/src/mir/tests/interface_dispatch.rs) and [MIR interface verifier](../../crates/skald-compiler/src/mir/verify/interfaces.rs). |
| The backend emits deterministic exact witness entries, preserves ordinary receiver/result ABI and shared ownership, and adds no runtime ABI service or version. | `generic_applications_emit_distinct_exact_witness_entries`, `generic_interface_shared_results_casts_and_dynamic_tests_keep_the_object_abi`, and `generic_interface_checked_failure_keeps_source_callable_trace_identity` in [backend interface tests](../../crates/skald-compiler/src/backend/x86_64_sysv/tests/interface_dispatch.rs); [runtime ABI contract tests](../../tests/runtime/test_runtime_contract.c). |

## Exclusion evidence

| Excluded feature | Evidence that it remains absent or unaffected |
|---|---|
| Compiler-generated primitive conformances | `closed_generic_interfaces_remain_invariant_and_nominal` rejects a primitive bound subject in [type-check tests](../../crates/skald-compiler/src/typeck/tests/generic_interfaces.rs); primitive box classes remain ordinary user classes. |
| Operator protocols, overloads, and primitive lowering through interfaces | `excluded_generic_interface_extensions_remain_syntax_errors` rejects operator requirements in [syntax interface tests](../../crates/skald-compiler/src/syntax/tests/interfaces.rs), while `generic_interface_bounds_do_not_enable_operators` in [type-check tests](../../crates/skald-compiler/src/typeck/tests/generic_interfaces.rs) proves an ordinary `Add<T>` bound does not authorize `+`; independent primitive operator suites continue to select only intrinsic typed operations. |
| Iterable/range/generator protocols within the generic-interface delivery | General iteration and ranges are separately owned implemented consumers; their structured HIR and execution remain outside this completed generic-interface evidence matrix. Generator protocols remain future work. |
| Generic functions, methods, constructors, and requirement-local parameters | `excluded_generic_interface_extensions_remain_syntax_errors` covers top-level, class-method, and requirement-local forms; lifecycle grammar tests retain nongeneric constructors. |
| Inference, defaults, placeholders, wildcards, raw types, generic aliases, and partial/explicit specialization | Malformed generic syntax tests and raw/arity resolver cases in [syntax interface tests](../../crates/skald-compiler/src/syntax/tests/interfaces.rs) and [failure goldens](../../tests/golden/generic_interfaces/failures.golden.toml); no inference entry exists in the resolved program. |
| Variance, existential applications, and implicit interface-to-interface conversion | `closed_generic_interfaces_remain_invariant_and_nominal` and exact cast/type-test tests in [type-check tests](../../crates/skald-compiler/src/typeck/tests/generic_interfaces.rs). |
| Associated types, higher-kinded parameters, same-type/base/negative/disjunctive/user-defined capability bounds | The implemented grammar admits only named type parameters and positive nominal interface applications; malformed-bound recovery in [syntax interface tests](../../crates/skald-compiler/src/syntax/tests/interfaces.rs) rejects other shapes. |
| Interface inheritance, default methods, nested declarations, static requirements, and method overloading | `excluded_generic_interface_extensions_remain_syntax_errors`, `recovers_after_an_invalid_interface_member`, and resolver duplicate-requirement tests in [syntax interface tests](../../crates/skald-compiler/src/syntax/tests/interfaces.rs) and [resolver interface tests](../../crates/skald-compiler/src/resolve/tests/interfaces.rs). |
| Structural conformance and qualified bound-member disambiguation | `closed_generic_interfaces_remain_invariant_and_nominal` rejects a shape-compatible undeclared class; ambiguous bounds remain a definition-time error with no qualification syntax. |
| Interface method references, boxing, escaping bare views, and implicit owner creation | `closed_generic_interfaces_retain_non_owning_view_exclusions` in [type-check tests](../../crates/skald-compiler/src/typeck/tests/generic_interfaces.rs). |
| Erasure, runtime dictionaries, reflection, runtime specialization, and template ABI | Lower-IR absence assertions in [MIR interface tests](../../crates/skald-compiler/src/mir/tests/interface_dispatch.rs), unchanged ABI marker tests in [backend interface tests](../../crates/skald-compiler/src/backend/x86_64_sysv/tests/interface_dispatch.rs), and cross-process whole-program specialization tests. |

## Closure gates

The complete profile is accepted only when `make check`,
`make golden-determinism-test`, `make msrv-check`, `make robustness-long`,
`make docs-check`, and `git diff --check` all pass from an artifact-free
snapshot.
