# Compiler Robustness Tests

Run the bounded deterministic corpus locally with:

```sh
make robustness-smoke
```

The ordinary Rust suite includes the same tests, so external clean-checkout
automation exercises the smoke corpus whenever it runs `make check`.

For a longer scheduled or pre-release run, use:

```sh
make robustness-long
```

`SKALD_ROBUSTNESS_CASES` controls the number of generated byte cases and valid
UTF-8 cases. Both targets use fixed seeds and bounded input sizes, so failures
are reproducible without adding fuzzing dependencies to production crates.

The frontend target covers source creation, lexing, parsing, and diagnostic
rendering. The MIR target mutates valid programs across identity, type,
ownership, call, place, control-flow, and cleanup invariants, then checks the
verifier and backend trust boundary. Retain any discovered regression as the
smallest focused test or corpus file under this directory.
